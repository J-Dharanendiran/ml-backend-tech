## 🧠 Learning Approach

This repository is not just a collection of SQL syntax.

For each concept, I try to understand:

1. **What it is**
2. **Why it exists**
3. **How it works**
4. **When to use it**
5. **How it relates to other SQL concepts**
6. **How to apply it in real queries**

The goal is to understand the underlying concepts rather than simply memorize commands.
