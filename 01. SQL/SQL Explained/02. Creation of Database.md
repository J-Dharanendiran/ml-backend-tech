# 02. Creation of Database

## What is a Database?

A database is a container used to store data so that it can be stored, retrieved, and updated efficiently.

### Simple Analogy

Think of a database like a folder:

```text
Database
│
├── Table 1
│   ├── Row
│   ├── Row
│   └── Row
│
├── Table 2
│   ├── Row
│   └── Row
```

The analogy is:

- Folder → Database
- File → Table
- Data inside a file → Data stored in rows

Another useful analogy is an Excel workbook:

- Excel Workbook → Database
- Excel Sheets → Tables
- Rows in a sheet → Rows in a table

The important idea is:

```text
Database
   ↓
Tables
   ↓
Rows
```

## What is a SQL Query?

Before creating a database, we need to understand what a query is.

A SQL query is essentially a command that tells the Database Management System (DBMS) what we want it to do.

For example:

```text
SQL Query
    ↓
Database Management System
    ↓
Performs the requested operation
```

Just as we perform an action by placing an order in an application, we perform actions on a database by issuing SQL queries.

## Creating a Database

Creating a database is one of the first and most important steps when starting with SQL.

To create a database, we use the `CREATE DATABASE` statement.

### Syntax

```sql
CREATE DATABASE database_name;
```

### Example

For this project, we create a database called `sql_learning`:

```sql
CREATE DATABASE sql_learning;
```

### What does this mean?

```text
CREATE DATABASE sql_learning;
      │         │
      │         └── Name of the database
      └──────────── SQL operation
```

This command tells MySQL:

> Create a new database named `sql_learning`.

The database name can be chosen according to the project or application.

## Executing the Query in MySQL Workbench

The query can be written in the SQL editor inside MySQL Workbench:

```sql
CREATE DATABASE sql_learning;
```

Then execute the query.

After successful execution, MySQL Workbench reports that the statement affected a row, indicating that the database has been created.

Next, refresh the Schemas/Databases panel in MySQL Workbench.

You should then see:

```text
sql_learning
```

among the available databases.

## Selecting the Database

Creating a database does not automatically mean that all future queries will use it.

We need to tell MySQL which database we want to work with.

There are two ways to do this.

### Method 1: MySQL Workbench

In MySQL Workbench:

1. Find `sql_learning` in the database/schema panel.
2. Right-click it.
3. Select **Set as Default Schema**.

Now `sql_learning` becomes the default database for subsequent queries.

### Method 2: Using SQL

We can also select the database directly using the `USE` statement:

```sql
USE sql_learning;
```

This tells MySQL:

> Use `sql_learning` as the database for the queries that follow.

After executing this command, subsequent SQL statements will operate on `sql_learning`.

### Why does `USE sql_learning;` show 0 rows affected?

When you execute:

```sql
USE sql_learning;
```

you may see:

```text
0 rows affected
```

This does not mean the command failed.

The `USE` statement does not create, update, delete, or read table data. It simply changes the currently selected database.

So:

```sql
CREATE DATABASE sql_learning;
```

creates the database.

Whereas:

```sql
USE sql_learning;
```

selects the database for subsequent work.

## Complete Flow

The basic database creation workflow is:

```sql
CREATE DATABASE sql_learning;

USE sql_learning;
```

In simple terms:

```text
CREATE DATABASE sql_learning;
          ↓
Create the database

USE sql_learning;
          ↓
Select the database

          ↓
Create tables and work inside it
```

## Key Commands to Remember

**Create a database**

```sql
CREATE DATABASE sql_learning;
```

**Select a database**

```sql
USE sql_learning;
```

## Summary

The process covered in this section is:

| Step | Concept | Command / Action |
|------|---------|-------------------|
| 1 | Understand a database | Database stores and manages data |
| 2 | Understand the hierarchy | Database → Tables → Rows |
| 3 | Understand SQL queries | Queries act as commands |
| 4 | Create the database | `CREATE DATABASE sql_learning;` |
| 5 | Execute the query | Run it in MySQL Workbench |
| 6 | Verify creation | Refresh the Schemas panel |
| 7 | Select through Workbench | Set as Default Schema |
| 8 | Select through SQL | `USE sql_learning;` |

**Note:** The next step after creating and selecting the database is creating tables inside the database.
